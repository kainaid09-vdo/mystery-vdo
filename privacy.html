개인정보처리방침 (Privacy Policy)

시행일 / Effective date: 2026-11-27

1. 앱 소개 / About the app

mystery uploader(이하 "앱")는 유튜브 채널 「미스터리 비디오」(@mystery_vdo)의 운영자가 자기 채널에 영상을 올리고 댓글을 달기 위해 쓰는 내부 도구입니다. 일반 이용자를 위한 서비스가 아닙니다.

mystery uploader is an internal tool used only by the operator of the YouTube channel "Mystery Video" (@mystery_vdo) to upload videos and post comments on that channel. It is not offered to the public.

2. 사용하는 구글 데이터 / Google user data used

앱은 YouTube Data API를 통해 운영자 본인 계정에 대해서만 다음 권한을 씁니다: 영상 업로드(youtube.upload), 자기 채널 영상의 댓글 작성·관리(youtube.force-ssl). 다른 사람의 계정, 개인정보, 시청 기록은 수집하지 않습니다.

The app uses the YouTube Data API only for the operator's own account, with the scopes youtube.upload (upload videos) and youtube.force-ssl (post and manage comments on the channel's own videos). It does not collect any other person's account data, personal information or viewing history.

3. 저장과 공유 / Storage and sharing

앱이 받는 인증 토큰은 운영자 서버에만 비공개로 보관되며, 제3자에게 판매·공유·전송하지 않습니다. 광고나 분석 목적으로 쓰지 않습니다.

Authorization tokens are stored privately on the operator's server only. They are never sold, shared or transferred to third parties, and are not used for advertising or analytics.

4. 권한 철회 / Revoking access

구글 계정의 서드 파티 액세스 관리 페이지에서 언제든지 앱의 권한을 철회할 수 있습니다.

Access can be revoked at any time at Google Account permissions.

5. 관련 약관 / Related terms

앱은 YouTube API 서비스를 사용합니다. YouTube 서비스 약관과 Google 개인정보처리방침이 함께 적용됩니다.

This app uses YouTube API Services. See the YouTube Terms of Service and the Google Privacy Policy.
